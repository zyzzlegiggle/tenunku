# Tenunku

Tenunku is an Indonesian online marketplace dedicated to the preservation and appreciation of traditional Tenun fabrics.

## About the Project
This project was developed for **Innovillage**, a Social Project Competition aimed at producing Young Technology and Digital Sociopreneurs.
The primary mission of Tenunku is to connect weavers directly with buyers, empowering local artisans and promoting sustainable fashion through technology.

## Overview

The platform connects weavers, sellers, and buyers, providing a seamless digital space for the trade of authentic Indonesian Tenun. It goes beyond a simple marketplace by including a unique section called "Benang Membumi" that focuses on educating users about the cultural significance of patterns, materials, and natural colors used in Tenun weaving.

## Key Features

- **Regional Marketplace**: Browse, filter, and purchase original Tenun products directly from verified weavers across various regions in Indonesia.
- **Seller Management System**: Comprehensive tools for sellers to manage inventory, update product details, handle orders, and control product visibility.
- **Secure Buyer Experience**: Features include secure shopping carts, favorite lists, detailed order tracking, and integrated Qris payment proofs.
- **Benang Membumi**: An educational sub-platform providing detailed insights into traditional weaving patterns, historical context, and the natural dyes used in specific regions.

## Tech Stack

- **Frontend**: Flutter
- **Backend**: Supabase
- **State Management**: Provider
- **Navigation**: GoRouter

## Getting Started

### Prerequisites

- Flutter SDK (version ^3.10.7)
- Dart SDK

### Installation

1. Clone the repository.
2. Run `flutter pub get` to install dependencies.
3. Configure Supabase environment variables if applicable.
4. Run the application using `flutter run`.
